# CodeLazy 開發移轉說明

## 專案資訊

- 程式名稱：CodeLazy
- 視窗標題：程式創作室
- 現行版本：V0.1.13
- 主程式：`CodeLazy_V0.1.13.pyw`
- 開發語言：Python 3.13
- GUI：PySide6
- 平台：Windows 10／11

## V0.1.13 更新重點

- 版號由 V0.1.12 升級至 V0.1.13。
- 啟動批次檔、Nuitka 打包檔、EXE 輸出名稱與版本資訊同步更新。
- 儲存資料並輸出同步檔時，若同步來源資料夾不存在，會先改存到程式所在資料夾。
- 預設雲端硬碟路徑不可用時，會輸出 `CodeLazy_sync.txt` 到程式所在資料夾。
- 2026-08-19 依使用者「同步」指令，發布最新版至 GitHub 與 Google Drive 的 `CodeLazy/V0.1.13/`。

## 執行方式

1. 安裝 Python 3.13。
2. 執行 `啟動_CodeLazy.bat`，程式會在缺少 PySide6 時自動安裝。
3. 若要建立單一 EXE，執行 `Nuitka_單一EXE打包.bat`。

## 現有功能

- macOS 半透明玻璃風格無邊框介面；標題置中、視窗控制鈕在右側。
- 新增、刪除、搜尋程式開發資料。
- 項次自動建立；刪除或同步後重新連號。
- 可在搜尋框清空時拖曳左側清單項目改變項次位置。
- 欄位：項次、名稱、檔名、初開發名稱、建立時間、最新版號、最後修改方式、說明、備註。
- 建立日期使用行事曆選取；每次展開行事曆都顯示今天所在月份。
- 最新版號格式為 `V##.##.##`，每段以直排 `+／-` 調整，範圍 0～99。
- 管理版號第一碼按 `+` 時第二碼設為 `1`、第三碼設為 `0`；第二碼按 `+` 時第三碼設為 `0`。
- 儲存後鎖定名稱、檔名、初開發名稱、建立時間及說明；按「修改」解鎖。
- 鎖定後右側基本資料與說明文字仍維持黑色，方便檢視已儲存內容。
- 最新版號、最後修改方式及備註在儲存後仍可直接更新。
- 左側清單載入或刷新時會檢查備註，備註非空白的項次整列顯示粉紅底色。
- 左側清單欄位：項次、名稱、檔名、最新版號、修改方式、更新時間。
- 本機資料以 UTF-8 JSON 儲存在程式旁的 `CodeLazy_data.json`。
- 每次儲存另存 UTF-8 JSON 文字檔至同步資料夾。
- 若同步來源資料夾找不到，會先將同步檔存到程式所在資料夾。
- 「同步」按鈕依各筆 `updated_at` 合併資料；較新的內容優先，刪除狀態也會同步。
- `同步` 右側 `+` 可自選同步紀錄檔；也可拖曳 `.txt` 或 `.json` 同步紀錄檔到視窗中載入。
- 最近使用的同步紀錄檔位置會存入 `CodeLazy_settings.json`。
- 雲端硬碟未連線時，本機資料仍會先儲存並顯示警告。
- 本機 JSON 損壞時會改名備份，再建立新的空資料庫。

## 資料與同步注意事項

- `CodeLazy_data.json` 是使用者資料，不應加入程式碼移轉包或公開版本庫。
- `CodeLazy_settings.json` 是本機設定檔，不應加入程式碼移轉包或公開版本庫。
- `CodeLazy_sync.txt` 雖然副檔名是 TXT，內容實際為 JSON。
- 每筆資料使用 UUID 作為跨電腦識別碼，不可改用項次當主鍵。
- `deleted` 字典保存已刪除 UUID 與刪除時間，避免舊電腦同步時讓資料復活。
- 同步比較依 ISO 8601 UTC 時間字串進行；修改時應保留時區資訊。
- 若變更資料結構，需在 `DataStore.normalize()` 中加入舊版本轉換，保持向下相容。

## 版本規則

- 一般修正或小功能增加第三碼，例如 V0.1.12 → V0.1.13。
- 較大的功能或架構變更才增加第二碼。
- 修改版本時需同步更新：
  - 主程式 `APP_VERSION`
  - Python 檔名
  - Nuitka 批次檔的來源檔名、輸出檔名與版本資訊
  - README 與本移轉說明
  - Google Drive 版號資料夾與交付 ZIP

## 驗證清單

- 執行 `python3 -m py_compile CodeLazy_V0.1.13.py CodeLazy_V0.1.13.pyw`。
- 執行 `python3 -m unittest discover -s tests -v`。
- 測試新增、修改、刪除與刪除後重新編號。
- 測試備註只有空白時不標色，有實際文字時才標成粉紅底色。
- 測試左側清單拖曳移位後項次重新編號，且畫面文字立即顯示。
- 測試重新啟動後 JSON 可正常載入。
- 測試兩份資料的新增、更新及刪除同步。
- 測試同步來源資料夾不存在時，會改寫到程式所在資料夾。
- 測試同步右側 `+` 可選取其他同步檔，並記住最後一次資料夾。
- 測試拖曳 `.txt` / `.json` 同步紀錄檔到視窗可載入。
- 測試預設雲端路徑不存在時仍能完成本機儲存。
- 在 Windows 10／11 實際檢查無邊框拖曳、最大化、縮小與調整大小。
